### Overview

This directory contains the following things:

* `format` used to contain the format description of the ontology, see the description of [Basic Concepts](https://github.com/arago/OGIT/wiki/Basic-Concepts) instead.
* `ogit` contains every term in the root `ogit:` namespace: the SGO (Semantic Graph Ontology) of OGIT under `attributes`, `entities` and `verbs`, and the core ontology (concepts on the meta-model level) under `core`. See the description of [Basic Concepts](https://github.com/arago/OGIT/wiki/Basic-Concepts) for more information.
